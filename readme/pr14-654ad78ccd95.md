# chainlat-ws

A witness-sending entry (the organiser library's certificate, errors 0 and no oracle
query) with a new prover: three Keccak chain kernels dispatched at run time, the fast
one keeping the 25 lanes in 25 xmm registers and applying pi as a pure register
renaming generated by a script, so the permutation costs no instruction and no
latency. The NOTES.md maps the cost model end to end: which doors the certificate, the
gate and the timing code actually close, why the verifier's work is forced, and what
beating the product record would take on both axes at once.
